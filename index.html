Quick Commands

/gc config
Enable, disable & configure Global Chat features. Set which channels participate in the global network and customize behavior to match your server.
/gc setup
Manage your personal Global Chat settings. Control notifications, visibility, and how you appear to other users on the network.
/gc stats
View comprehensive Global Chat network statistics. See server counts, active users, message volume, and your personal contribution.
/gc profile
View a user's Global Chat profile card. Check reputation, activity level, and contribution history across the entire network.
